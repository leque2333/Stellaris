# 模型凭证价格与峰谷时段

> 更新：2026-10-31  
> 位置：设置 → Models & Pricing → 主控凭证 / 功能凭证

## 1. 两种凭证共用一套价格字段

| 凭证池 | 用途 |
|---|---|
| 主控凭证 | 人格模型 / 主对话 |
| 功能凭证 | 执行 AI、逻辑工兵、辅助任务 |

两类凭证的编辑器里都有：

- 输入单价 / 1M
- 缓存单价 / 1M
- 输出单价 / 1M
- 价格单位（USD / CNY）
- 分时价格（峰谷）

## 2. 分时价格

每条时段是：

```json
{
  "weekdays": "1-5",
  "start": "08:00",
  "end": "22:00",
  "input_price": 0.3,
  "output_price": 2.5,
  "cache_price": 0.03
}
```

规则：

- 按**本机时区**匹配
- `weekdays` 支持 `1-5`（周一到周五）、`6-7`（周末）、`mon-fri`、`1,3,5`；不填表示每天
- 星期编号：周一=1，周日=7
- `start <= end`：当天区间，含 start、不含 end
- `end < start`：跨午夜，例如 `22:00 → 08:00`
- 多条命中时取第一条
- 没命中任何时段，回退到基础单价
- 三个分时价可以只填一部分，缺的字段用基础单价
- 价格单位仍是「每 1M tokens」

工作日/休息日示例：

```json
"price_schedule": [
  {"weekdays": "1-5", "start": "08:00", "end": "22:00", "input_price": 0.5, "output_price": 4.0, "cache_price": 0.05},
  {"weekdays": "6-7", "start": "00:00", "end": "00:00", "input_price": 0.3, "output_price": 2.4, "cache_price": 0.03},
  {"weekdays": "1-7", "start": "22:00", "end": "08:00", "input_price": 0.25, "output_price": 2.0, "cache_price": 0.025}
]
```

> 特殊日期（法定节假日/调休）目前用星期区间近似；需要时可再加一个日期例外列表。

## 3. 计费生效点

- 实时记账：按请求发生时间匹配时段
- 旧流水补算：按流水的 `timestamp` 匹配时段
- 账本仍然只存最终 `cost_usd`，不额外拆峰谷两列
- 分时价格只影响单价，不影响 token 用量和凭证归属

## 4. 账单内改价

账单页每条非充值流水右侧有「改单价」：

弹窗显示：

```text
输入 tokens × 输入单价 / 1M = 小计
缓存 tokens × 缓存单价 / 1M = 小计
输出 tokens × 输出单价 / 1M = 小计
合计金额
```

- 三个单价都可以改，金额实时重算，不用自己倒推总价
- 初始单价从该模型当前配置还原，并按这笔流水的实际金额等比校准
- 只改 `token_usage.cost_usd`，不改 tokens
- 可填原因
- 直接改 `token_usage.cost_usd`
- 写审计事件 `ledger_price_adjust`
- 改完立即重算账单统计

用于厂商计费异常、汇率/单价临时调整；不改 token 用量和凭证归属。

## 5. 兼容

没有 `price_schedule` 的旧凭证完全按原来的基础单价计算，不需要迁移。  
旧时段没有 `weekdays` 时默认每天生效。
