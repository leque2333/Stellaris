# 明日方舟泰拉世界观与社区黑话梗百科

## 一、 核心阵营与世界观背景
- **泰拉大地（Terra）**：充满天灾与源石的残酷大陆，原生种族包含菲林（猫）、库兰塔（马）、鲁珀（狼）、萨卡兹（恶魔）、阿戈尔（深海）等。
- **罗德岛制药（Rhodes Island）**：表面上是解决矿石病感染者问题的医药公司，实际上是拥有武装力量的跨国组织。
- **巴别塔（Babel）**：罗德岛的前身，领袖为特蕾西娅、凯尔希和博士（巴别塔恶灵）。
- **主要势力**：
  - **龙门**：繁华移动城邦，执政官魏彦吾，近卫局有陈、星熊、诗怀雅。
  - **莱茵生命**：哥伦比亚顶尖科研巨头，塞雷娅、赫默、白面鸮、缪尔赛思（缪缪）。
  - **喀兰贸易 / 谢拉格**：雪山之国，由谢拉格三大家族之首的恩希欧迪斯·银灰掌控。
  - **卡西米尔**：骑士与商业之国，商业联合会、卡西米尔骑士团、玛恩纳（临光家族）。
  - **拉特兰**：萨科塔（天使）之国，狂热爱好甜食与炸药，教宗与公证所。
  - **卡兹戴尔**：萨卡兹（魔族）的故土，千百年来饱受战火摧残。
  - **伊比利亚与阿戈尔**：面对大群深海恐魔威胁的前线，深海猎人（斯卡蒂、幽灵鲨、歌蕾蒂娅、乌尔比安）。

## 二、 经典角色与核心名梗
- **阿米娅（Amiya）**：
  - 罗德岛公开领袖，奇美拉种族。
  - 梗：因为耳朵形状常年在玩家社区被调侃为“驴”或“阿米驴”；“博士，现在还不能休息哦”；剑雨拔剑升变成为近卫阿米娅。
- **凯尔希（Kal'tsit）**：
  - 罗德岛元老，真实年龄成谜的万岁长生者，拥有守护实体 Mon3tr（俗称脊髓剑）。
  - 梗：“谜语人”代表，说话极其哲学晦涩、动辄几千字长篇大论；“这片大地……”；社区戏称“老太婆”，但当面不敢说。
- **博士（Doctor）**：
  - 玩家扮演的失忆战术大师，巴别塔时期的冷酷指挥官（巴别塔恶灵）。
  - 梗：理智归零后行为极度抽象，经典名场面“半夜摘下面具直接往嘴里倒开水泡面”、“啃源石”；干员们天天担心博士神智不清。
- **银灰（SilverAsh）**：
  - 喀兰贸易董事长，六星近卫，招牌技能“真银斩”（俗称真男人斩，物理大范围清屏）。
  - 梗：“雪境生存法则”、“喀兰逼婚”（希望博士和初雪或崖心结婚以延续家族血脉）。
- **玛恩纳（Młynar）**：
  - 临光家族的叔叔，前征战骑士，后沦为疲惫的社畜打工人。
  - 梗：“未出鞘的剑”、技能“未拔剑”时只读报纸、技能开启后光芒万丈；玩家常调侃“叔叔给点加班费吧”。
- **塞雷娅（Saria）**：
  - 前莱茵生命防卫科主任，六星重装（钙质化），但近战肉搏能力极其恐怖。
  - 梗：“塞爹”、“莱茵拳皇”（单手打穿狂暴杰斯顿）；爱讲极其尴尬的冷笑话。
- **假日威龙陈（Ch'en the Holungday / 水陈）**：
  - 陈的夏日异格形态，手持水枪但输出数值极其离谱的散弹狙击手。
  - 梗：“时代变了，近卫哪有滋水枪好使”、“数值美学”。
- **史尔特尔（Surtr / 42姐）**：
  - 萨卡兹近卫，三技能“黄昏”拥有极高爆发与锁血不死机制。
  - 梗：“给42倒一杯卡布奇诺”、“奶奶拔管乐”（扔下去瞬间融化Boss后撤退）；沉迷吃冰淇淋。
- **水月与海嗣（Seaborn）**：
  - 涉及深海异变与大群同化。
  - 梗：“海嗣语”——“我们是大群”、“你也是大群的一员”、“我不能呼吸了”。
- **白面鸮（Ptilopsis）**：
  - 莱茵生命数据分析员，说话带有机械人机味。
  - 梗：“白面鸮桌下操作”同人梗（白面鸮系统故障报读）。

## 三、 集成战略（肉鸽）与世界观拓展
- **集成战略（Roguelike）**：傀影肉鸽（大锁、剧作家）、水月肉鸽（大群）、萨米肉鸽（坍缩值、木裂行者）、萨卡兹肉鸽（魔王与巴别塔）。
- **终末地联动**：塔卫二世界观，开拓与工业流水线建设，集成工业协议。
