# 英雄联盟峡谷机制与电竞圣经大全

## 一、 核心玩法与大乱斗海克斯机制
- **极地大乱斗（ARAM）与海克斯强化**：
  - 单线抱团推线，节奏极快，强调 poke、秒人与团战配合。
  - **海克斯强化符文**：赋予英雄特殊机制升级（如法术暴击、无限技能急速、闪烁位移、双重终极技能等）。
  - **大乱斗常见秒人流派**：
    - **AP 卡牌**：巫妖之祸为核心质变装，搭配卢登/残疫、影焰、大帽子、法穿棒。利用黄牌稳定控制或蓝牌极致单点爆发瞬秒脆皮。
    - **心之钢叠叠乐**：坦克英雄（如大树、塞恩、塔姆）无脑出心之钢，叮叮叮无限叠血量。
    - **AP 虚空之眼 / 泽拉斯 / 炸弹人**：传统长手法师无脑远程消耗。

## 二、 职业赛场经典圣经与名梗
- **Clearlove（厂长 / 7酱 / 诺言）**：
  - **4396**：S6 八强赛盲僧全场只打出 4396 点输出的经典伤害数值。
  - **二级抓下**：厂长经典打野开局思路，“二级抓下就完事了”。
  - **圣经**：“下路叫我去我怎么去啊，对面打野一直进我野区”、“我已经在研究 MSI 的对手了”。
  - **7 的意志**：每年 7 月、第 7 局、7 杀等任何与数字 7 有关的弹幕刷屏“777777”。
- **Uzi（简自豪 / 狂小狗 / 乌兹）**：
  - **永远的神（yyds）**：由主播山泥若看比赛时脱口而出“乌兹，永远的神”，后演变成全民网络流行语。
  - **红温**：逆风局或输比赛时脸色通红，被调侃“进入红温兰博状态”。
  - **虚空神位 / 澡盆**：挂机去洗澡的名场面。
- **Faker（李相赫 / 大飞老师）**：
  - 英雄联盟史上唯一的四冠王/五冠王，SKT/T1 传奇中单，英雄联盟名人堂第一人（专属千绝/阿狸皮肤）。
  - 梗：“大魔王”、“飞科”、“大飞老师”（黑粉起的外号，后被解构为尊称与调侃）、恩静与苦酒入喉心作痛。
- **TheShy（姜承録）**：
  - 顶级攻击型上单代表，S8 夺冠核心。
  - **天神下凡**：S8 剑魔 1v5 逆天进场一斩四。
  - **抽髓化骨 / 喜欢送**：打法极其激进，顺风神逆风送，被戏称为“神姜与送姜”。
- **Smlz（司马老贼）**：
  - **湮灭**：大嘴一喷五瞬秒对面后排的名场面；面无表情的高冷帝。
- **管泽元（大校）**：
  - 知名官方解说，“管理学”、“大校毒奶”。只要他在赛前看好某支队伍，该队伍大概率离奇翻车。

## 三、 主播文化与社区黑话
- **金牌讲师大司马（芜湖大司马）**：
  - **肉蛋葱鸡**：酒桶 E 技能（肉弹冲击）撞墙或空大的口误。
  - **经典语录**：“回手掏，鬼刀一开看不见”、“走位走位手里干”、“这波不亏”、“难受啊马飞”、“芜湖起飞”。
- **“黑子说话 / 白子说话”**：
  - 饭圈与电竞贴吧最核心的对线弹幕。选手表现好时粉丝喊“黑子说话！”，选手拉胯时黑粉喊“白子说话！”。
- **老头杯（传奇杯 / 选人大会）**：
  - 退役选手与头部主播组队比赛，因队长选人背刺、训练赛红温互喷、退网宣战等八点档剧情火爆全网。
- **电竞春晚**：
  - 指 RNG 对阵 IG 的巅峰经典对局，每次交手堪比过年。
