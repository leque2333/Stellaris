预留开放接口规范 (Open Agent Module Specification)
我们是小众软件，不强求外部专门开发插件；但若有开发者想原生接入我们，只需遵循以下最简规范（零繁琐框架依赖，单文件即插即用）。
方式 1：Python 极简装饰器标准 (Zero-Dependency SDK)
# 在任意插件 main.py 或独立脚本中：
from agent_core import agent_tool

@agent_tool(
    name="query_stock_price",
    description="实时获取股票或外汇即时价格",
    tags=["finance", "tool"]
)
def get_price(ticker: str, currency: str = "USD") -> str:
    # 系统根据类型注解自动推断 JSON Schema，大模型可直接调用
    return f"{ticker}: 182.50 {currency}"
